# 🍇 Grapefix

**Grapefix** is a lightweight add-on for **Create: Alcoholic Beverages** on **NeoForge 1.21.1**, introducing a fully functional grape crop essential for winemaking.

---

## ✨ Features
* **Grape Crop (`grape_crop`)**: A multi-stage crop with custom growth logic and harvest mechanics.
* **Grape (`grape`)**: An item that can be consumed as food or used for planting.
* **Integration**: Items are automatically integrated into the official creative tab of the *Create: Alcoholic Beverages* mod.
* **Localization**: Full support for both **English** and **Russian** languages.

---

## 📦 Requirements
This mod requires **NeoForge** and the following mod to be installed:
* [Create: Alcoholic Beverages](https://www.curseforge.com/minecraft/mc-mods/create-alcoholic-beverages) (1.21.1 version)
